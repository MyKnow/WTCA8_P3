# kotlin-lotto-precourse
# 기능 목록

---

- 구입금액 안내문을 출력하고 입력 받는 기능
- 입력된 구입금액이 올바른 포맷인지 확인하는 기능
- 구입금액을 토대로 로또 수량을 계산하는 기능
- 로또 수량을 출력하는 기능
- 구매 번호를 오름차순으로 생성하는 기능
- 구매 번호를 출력하는 기능
- 당첨 번호 안내문을 출력하고 입력 받는 기능
- 입력된 당첨 번호가 올바른 포맷인지 확인하는 기능
- 보너스 번호 안내문을 출력하고 입력 받는 기능
- 입력된 보너스 번호가 올바른 포맷인지 확인하는 기능
- 구매 번호와 당첨번호+보너스 번호를 대조하여 로또 등수를 산출하는 기능
- 당첨 통계를 출력하는 기능
- 총 수익률을 계산하는 기능
- 총 수익률을 출력하는 기능
